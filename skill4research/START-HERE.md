# skill4research 通用编排包

当前版本把具体候选数、领域、设备、样本比例和门槛移到任务约定。包含两套完整 skills、六个项目的历史源码调研与行为审阅。名称保持兼容，允许隐式选择。未安装个人全局技能，未启动实验或后台服务。

## 两套职责不同的流程

| 需求 | Skill | 核心 |
|---|---|---|
| 忠实复现指定论文实验/主表 | paper-reproduction-team | 规划、独立计划核查、执行修改、独立实现结果核查；证据和版本对应 |
| 持续提出、质询、验证和修正假设 | overnight-research-loop | 提案、idea 把关、独立验证反思、执行；实时反馈、争论与机制多元化 |

角色数不等于同时进程数，也不扩大计算资源。协调者负责流程；审查者对证据负责；作者不能替自己签独立批准。两套技能都明确版本化通知、回执、相关任务暂停/改向及项目内经验。

## 研究流程如何反对和转向

发现同质化或负证据→保存质询和影响范围→主动通知相关活跃 agents→确认并限制旧判断的派发→提案者回应最强反对→把关者解释漏检并重新比较→独立反思者复核→深化/诊断/修改/放弃/搁置→同步新决定→新一轮。

把关者不是单纯赞同者；反思者可批评其放行理由，要求说明忽略哪个实验、哪个前提不成立、同族候选如何受影响。反对方也须回应有效反驳；不以地位、投票或争论次数决定科学结论。

多样性按问题前提、机制、信息来源、目标/监督、流程与预测判断。改名或小参数变化归为 refinement，不计新方向。充分反证可放弃具体版本/机制族；不把局部负结果推广为整个主题永久失败。经验保存来源、范围、反例和重启条件，供后续把关实际使用。

## 每次任务填写什么

目的与目标实验/问题；原始资料及历史记录；资源和结束条件；基线、评价依据和成本约束；角色及可写范围；持久目录和续接方式。候选组合、样本选择、扩大规模、统计与门槛按当前任务制定。已有信息能核实的不重复询问。

## 安装与发现

将 skills/ 的两个完整目录复制到环境支持的个人或项目发现目录，保留 agents/、references/ 相对关系。当前官方文档列出个人 C:\Users\dasou\.agents\skills 和项目下 .agents/skills；本会话亦提供 .codex/skills 来源，应按宿主版本确认可用列表，不重复同名安装。参见 [发现规则](https://learn.chatgpt.com/docs/build-skills)。

也可直接要求 AI 读取本包 SKILL.md 的绝对路径并执行。仅有文件不能声称全局安装或后台运行已完成。

## 调用示例

```text
使用 $paper-reproduction-team 复现指定论文的目标实验。
资料和项目：[位置]；目标：[实验/表格]；资源与结束条件：[约定]。
请明确角色权限，独立重建配方并核查，完成实现和结果审计。
新发现及时反馈给受影响的活跃 agents，收确认并按版本返工。
```

```text
使用 $overnight-research-loop 持续研究 [问题]。
历史资料和项目：[位置]；资源、评价依据和结束条件：[约定]。
明确提案、idea 把关、独立反思和执行职责。
发现同质化、重复失败或负证据，及时通知正在工作的相关 agents；
要求把关者回应遗漏，组织证据质询；充分时放弃并转向更本质/不同机制。
把有范围的经验写入项目，使下一轮使用它；一项实验结束后继续。
```
