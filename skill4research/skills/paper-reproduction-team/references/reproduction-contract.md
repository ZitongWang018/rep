# 复现契约与证据

在 `plan.md` 写目标实验/表格编号、比较对象与数据/环境、论文版本和来源、作者仓库 URL 与 commit、用户给定资源与截止条件、预期产物。目标是该实验主配方；若目标是作者代码行为、缩减版或公平对照，单独标注。按领域选择适用字段；没有训练环节不要求训练配置，没有逐样本概念时使用实验单位/试次/场景级证据，不制造不适用的要求。

## 逐字段证据矩阵

保存为 `recipe-matrix.md`，每行包含：`字段 | 目标值 | 来源及定位 | 实际值及证据 | 状态 | 影响/处理`。状态区分已验证、推断、冲突、未知、不适用。来源定位使用论文页/节/表、源码路径与行、配置键和 commit；实际值使用解析后配置、代码路径、日志和数据清单。仅抄配置文件不足以证明实际运行使用了它。

覆盖与任务有关的字段：

| 类别 | 应确认的主配方 |
|---|---|
| 数据/材料/环境 | 来源与版本、取得方式、数量、选择/划分、处理、标签或观测生成、信息泄漏边界 |
| 方法/系统 | 算法与关键流程、初始化、结构、实现差异、数值精度、条件与依赖；模型实验按需查架构和参数 |
| 执行协议 | 步骤、迭代/重复次数、随机性、停止条件、恢复状态；训练实验按需查目标、优化器、batch 和训练量 |
| 比较 | 对照来源、相同数据/条件与选择预算；不同资源口径分开报告，不能互换 |
| 评价 | 测量/评分工具、输入与访问规则、单位/场景、指标定义与聚合、选择规则、不确定性 |
| 资源 | 设备、并发、时间/成本、存储、可恢复方式；只核对任务实际使用的资源 |

## 冲突处理与计划冻结

为每个冲突记录正文、附录、作者代码各自值，定位哪个实际对应目标表格。必要时在可承担成本内测试会实质改变结论的分支；不能仅因为实现方便而静默选择。无法确定的项写入偏差登记，说明为什么选择当前值和会影响哪些结论。

先确定比较口径：绝对差、相对差、百分点，及论文已报告的方差/种子数。未报告方差时不杜撰容差；可预先选定实用容差并说明它是本次标准。单种子结果不能冒充论文多种子均值。除非另有明确设计，不根据测试结果改变容差、种子或 checkpoint 选择规则。

计划核查通过后保存计划版本及 hash、源码 commit 或文件 manifest/hash、完整解析配置及 hash、数据/划分 manifest、环境依赖、随机种子、启动方式。大数据可记录原始版本、样本 ID 清单/校验和与处理脚本版本，不必给每个大文件重复计算昂贵 hash。变更影响目标字段时产生新版本和核查记录。

审查记录绑定 review_id、计划/源码/config/data/evaluator 的身份及覆盖字段。运行前核对当前版本与批准版本，run 保存所依赖的 review_id；不一致时阻断相关派发并重审变更。完成时记录结果 manifest/hash，结果核查绑定该产物；评分器、样本或聚合改变后不能沿用旧结果批准。发现通知和争议按 agent-roles.md 处理，保留批准被撤回/限定的历史。

## 可选预算核算

仅在论文用训练 token、样本或计算量定义协议时核算对应口径。例如 `总训练 token = 实际更新步数 × 每步全局有效 token`；有效 token 的 padding、mask、packing、梯度累积和并行重复计数规则须按论文/实现定义，并通过实际日志验证。固定长度且无截断/填充差异时才可简化为 steps × global_batch × sequence_length。这不是所有论文的必需公式；等参数、等样本、等 token、等 FLOPs 与等 GPU-hours 分开报告，不能互换。

## 运行与结果证据

每次 run 记录 `run_id、目标/类型、方法与配置版本、数据/材料/环境版本、随机性、设备、job/PID 或执行身份、开始/结束、退出/错误、日志、中间产物、评价文件、成本`。低成本检查验证可执行、恢复与测量路径，不替代完整实验。恢复须核对本任务有状态的组件与进度；训练任务按需核对 optimizer/scheduler/RNG 和数据位置，记录不完全恢复的影响。

长运行结合调度状态、进程、日志增长、checkpoint 时间与实际 metrics 监测；监测周期按预计训练速度设置。定期检查不等于必须固定每分钟查询。发现 OOM、无进展、NaN、评估缺失、资源漂移及时修复，在授权范围内恢复并保留记录。到截止条件时保存可继续状态并如实报告。

最终比较表包含 `目标实验 | 论文值及口径 | 实测值及口径 | 差值 | 已完成规模/重复数 | 协议缺口 | 核查状态`。先确认测量、产物身份和执行规模，再解释差距。分开表述：

- 配方对齐且数值落入预定比较范围；
- 配方对齐但数值偏离，原因已证实/仍未明；
- 存在协议差异，因此只能报告近似复现/缩减实验；
- 证据不足或运行未完成。

不把低方差局部集、作者 best run 与本次 mean、累计筛选后的测试最优或同名不同版本 benchmark 混为可直接比较的数字。
