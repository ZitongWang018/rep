# 质询、实时反馈、多元探索与经验学习

## 立即反馈的情形

实质重复过去尝试却无新增证据；多候选共享已被质疑前提；原始结果反对核心预测；实现/评估问题使旧结论失效；把关遗漏负结果或夸大代理量；出现更有解释力且可区分的替代机制。

明显不 work 须有可检查依据，如必要通路不存在、关键预测被有效试验反驳、实测收益/成本不符任务。未知、一次故障或不匹配旧实验不等于反证。缺证据且成本高可以 park，不假造 reject 的确定性。

处置按影响与依据分级：可靠关键反证限制相关新派发并复核；尚未验证但可信的问题优先安排区分性诊断，可保留不依赖该前提的动作；纯偏好或无证据的反对不获得无理由否决权。验证者须说明阻断依据、范围和解除条件，自己的错误或过度否定也接受质询。共同承认的不确定性可在诊断授权内探索，不能包装成已确认。

## 反馈闭环

1. **保存质询。** 发现者写 challenge_id、原始证据、范围、候选/版本、受影响任务、原放行理由为何不足、解决证据或动作，区分关键与可边做边查的问题。
2. **立即传播。** 协调者使用真实协作工具通知提案、把关、验证和受影响执行者，同步状态并限制相关新派发。无关任务继续。只写最终报告不算完成反馈。
3. **收到并行动。** 活跃 agents 在下一安全交互边界确认 acknowledgement、当前 work/job、暂停或修改动作及回应时间。投递不等于确认，沉默不等于同意。按约定反馈时限重送/查询，必要时中断相关新动作、安全保存，不越权杀进程。
4. **回应最强反对。** 提案者接受、限定、给新证据、提最小诊断或撤回；解释真正差异，不能换名重提。
5. **把关者重新判断。** 说明原遗漏、受影响同族候选与修订的筛选依据。不能只转发作者；旧批准失效，新判断绑定版本与证据。
6. **独立复核。** 验证者检查反对是否真正解决、是否移动目标或靠无依据辅助假设自救。未解决时保留问题，提出更本质解释；被有效反驳则撤销/缩小自己的质询。
7. **决定与同步。** 协调者记录 proceed / revise / diagnostic / park / abandon；不能把未解决科学问题改写为通过。有信息价值的诊断可仅获 diagnostic 批准，不当作正式晋级。给相关 agents 发新版本/动作并收确认，再推进依赖。

争论到有决策依据，不固定轮数；无新证据时转区分性动作或暂搁置，继续其他方向，不空转。多数票、角色地位和争论时长不替代证据。协调者选资源内下一动作，独立验证者决定证据问题是否解决；两者不相互越权。

## 对把关者的批评范式

> challenge_id / 候选版本：你放行中的 [具体主张] 未解释历史实验 [run_id] 在 [条件] 下的 [观测]。当前候选仅改变 [表面变量]，未改变 [失败前提]。请重读原始证据，说明实质差异、重试证据和原审查遗漏；重新比较不同机制。无法回应则撤销此版本推荐，登记同族影响与复查条件。

批评针对可修正判断，不羞辱角色；把关者可以提供有效证据反驳，避免反思者过度否定有价值方向。

## 多样性依据机制

mechanism_signature 可包含问题/失败假设、作用机制、干预/流程、信息来源、目标/监督、条件和预期观测。按领域裁剪，列历史近邻及关键区别。

同机制小参数变化可作为 refinement 或稳健性，不计新方向。预测相同且受同条反证影响的候选归为一族；不为多样性强制无逻辑尝试。

同质化后共同重新问：真正瓶颈是什么？原因假设是否错了？能否改变信息来源、目标、表示/流程、监督、交互、问题分解或评估解释？哪些替代机制对已知观测有不同预测？借相邻领域思想时说明迁移条件。

候选 portfolio 可容纳有证据的深化、区分根本解释的诊断和不同机制探索；按信息价值、证据与成本分配，不固定 top-k、配额或比例。

## 放弃、搁置与重启

放弃该版本/机制族的依据：必要预测在合适且有辨别力的试验中失败；新条件不能解释旧反证；收益/成本不合任务；重复失败机制无有关变化；充分证据否定必要通路。限定适用范围，不等于放弃整个主题。

park 用于缺证据、资源或依赖。reopen 须有具体新证据或与失败有关的条件变化，换名字/措辞不能自动重启；旧失败若是实现或评估故障，修复核实后可重启而无需虚构科学差异。

## 项目内学习

lesson 保存来源 run/challenge、观测、解释与不确定性、适用范围、下次核对动作、反例/重启条件和版本。把关者下一轮说明用了哪些相关 lessons、影响哪些候选；验证者检查实际使用。新证据能修订旧经验，保留出处与版本。

历史比较不是禁词列表；不把局部失败变永久禁令。跨会话经验写项目文件，未经明确要求不改个人记忆。合并同族记录但不丢原始证据。
